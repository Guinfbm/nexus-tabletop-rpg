# NEXUS//TABLE

Mesa virtual de RPG cyberpunk com mapa interativo, tokens, chat, rolagens,
fichas PDF e ferramentas locais para o Mestre.

## Documentação

- [Manual completo das funcionalidades](DOCUMENTACAO_FUNCIONALIDADES_NEXUS_TABLE.txt)
- [Requisitos de melhorias da interface](REQUISITOS_MELHORIAS_INTERFACE.txt)

O site atual funciona localmente no navegador. A sincronização cobre abas da
mesma origem e navegador; não há backend ou multiplayer pela internet.
